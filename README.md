# 📱 WhatsApp GroupDNA Analyzer

## 📌 Project Overview

This project was developed as Minor Project 1 during my Unlock Academy Summer Internship.

The WhatsApp GroupDNA Analyzer processes exported WhatsApp chats and generates useful insights using Python.

---

## ✨ Features

- Chat Parser
- Group Overview
- Most Active Day & Hour
- Activity Heatmap
- Top Words Analysis
- Response Speed & Silent Streaks
- Personality Archetypes
- Final Report
